## 扫出你的"思维bug"

- **偏见检测**：20+常见认知偏见，多维度扫描
- **训练模式**：测验+分析，针对性提升思维质量
- **自定义规则**：编辑检测规则，适配个人场景
- **置信度分级**：高/中/低三级，精准定位问题

## 怎么用

打开 `standalone.html` → 开始扫描 → 查看诊断报告
